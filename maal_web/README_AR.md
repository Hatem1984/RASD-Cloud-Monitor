## الوظائف المنفذة والمختبرة
1. لوحة القيادة بملخص تنفيذي على خلفية عاجية عالية التباين، يربط حالة خبر **تاريخي** حقيقي بفرصة متابعة لشركة **افتراضية**.
2. جرد 13 مصدرًا مفعّلًا بالإعدادات، 29 عبارة رصد، و50 مصدرًا بحثيًا؛ **ليست بيانات تشغيل حية**.
3. قائمة مصادر مختصرة (6) قابلة للتوسعة (13) والبحث؛ فتح بطاقة تفاصيل كل مصدر تتضمن URL وallowed article hosts، ولا تدعي صحة الاتصال في اللحظة الحالية.
4. غرفة أدلة تُظهر صورة الناشر الحقيقي وتاريخ النشر بدقة **يوم فقط** مع آخر وقت فحص موثق منفصلًا، وبصمة SHA-256.
5. تنزيل تقرير Word الأصلي **فقط إذا** تحققت مطابقة الصورة المضمّنة ببصمة صفحة الناشر المصرح بها، وإلا رفض الطلب بأمان.
6. تحليل صريح يقسم المعلومة إلى حقيقة، أثر مشروط، وعناصر لم يثبتها الدليل.
7. مراجعة توصيتين غير منفذتين؛ مذكرة مراجعة تُكتب داخل الصفحة وتُنسخ يدويًا؛ **لا حفظ ولا إرسال ولا تمثيل لموافقة**.
8. بحث تنقّل محلي `Ctrl+K`، تنقل بلوحة المفاتيح وEscape، وتقسيم متجاوب للكمبيوتر والتابلت والموبايل.

## المعمارية النظيفة (بلا خدمات مدفوعة)
- `server.py`: واجهة بيانات محلية محددة المسارات، مع التحقق من السجل والبصمة قبل كشف الدليل أو مستند Word، وممنوع POST.
- `app.js`: تحميل بيانات فقط، ربط نصوص عبر textContent لمنع حقن HTML، مدير تنقل وفلتر ومراجعة مؤقتة.
- `index.html`: بنية HTML عربية RTL مع عناصر دلالية وتسلسل أقسام واضح.
- `style.css`: متغيرات هوية معتمدة وحالات استجابة للشاشات، لا يحتاج CDN أو ملفات خطوط للتوزيع.
- `test_dashboard.py`: اختبارات العقود والبصمات وحماية الطلبات.
